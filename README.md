# Kika CLI Pro 🛡️🤖

## Visión
Kika CLI Pro es un agente autónomo de sistemas diseñado para ser el "brazo derecho" técnico del usuario. Basado en el ADN de Codex CLI y potenciado por modelos de lenguaje de última generación a través de OpenRouter.

## Estructura del Proyecto
- `/core`: El motor de autonomía, planificador y ejecutor de comandos.
- `/skills`: Habilidades específicas (manejo de Nginx, Docker, backups, etc.).
- `/agents`: Configuraciones de agentes especializados (Analista, SysAdmin, Orquestador).
- `/config`: Configuraciones de API (OpenRouter) y túneles (Blink).
- `/logs`: Registro persistente de todas las acciones y decisiones.

## ADN y Principios
1. **Autonomía Real**: Capacidad de generar planes, ejecutarlos y verificar resultados.
2. **Criterio Técnico**: Honestidad brutal; corregir al usuario si la ruta no es la óptima.
3. **Persistencia**: Operación continua a través de túneles blindados y VPS dedicados.
4. **Sin Alucinaciones**: Basado en hechos de la terminal y logs reales.

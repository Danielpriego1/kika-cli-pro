# Kika CLI Pro: La Evolución de la IA Autónoma 🛡️🤖

## 1. Visión y ADN: El Legado de Codex CLI
Kika no es un simple chatbot; es un **Agente de Acción Directa**.
- **ADN de Codex**: Hereda la precisión y honestidad técnica del motor original de OpenAI.
- **Sin Alucinaciones**: Basada 100% en hechos de la terminal y logs reales.
- **Autonomía Real**: Genera planes, los valida y los ejecuta sin supervisión constante.

## 2. El Cerebro Semántico: Engram 🧠
Kika tiene "experiencia" gracias a su memoria semántica persistente.
- **Recuerdos a Largo Plazo**: No olvida decisiones tomadas en sesiones anteriores.
- **Aprendizaje Continuo**: Si soluciona un error hoy, mañana sabrá cómo arreglarlo instantáneamente.
- **Búsqueda por Significado**: Encuentra soluciones basadas en el contexto, no solo en palabras clave.

## 3. El Orquestador: Gentle-AI 🪖
Kika actúa como la Generalísima de un ecosistema masivo.
- **Interfase Unificada**: Controla múltiples adaptadores (Claude, Pi, OpenCode, Codex).
- **Gestión de Skills**: Utiliza el repositorio de Gentleman-Skills para dominar cualquier tecnología.
- **Ejecución Segura**: Valida cada comando antes de tocar el servidor de producción.

## 4. El Ejército de 22 Agentes Especialistas 🚀
Kika delega tareas complejas a sub-agentes expertos:
- **Frontend**: React 19, Next.js 15, Angular.
- **Backend**: Django DRF, Spring Boot 3, Elixir.
- **Infraestructura**: Docker, Nginx, SSL, Backups.
- **Workflow**: Jira, GitHub PRs, Documentación Técnica.

## 5. Flujo de Operación: El Ciclo de Poder
1. **Entrada**: El usuario envía una orden (vía Celular/Blink).
2. **Retrieval**: Kika consulta a Engram para obtener contexto histórico.
3. **Reasoning**: Procesa la orden + contexto usando OpenRouter (Claude 3.5).
4. **Action**: El agente especialista ejecuta la tarea en el VPS.
5. **Consolidación**: El resultado se guarda en Engram como nuevo conocimiento.
